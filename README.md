# Science Museum - Inspiring Young Minds

## 📌 Project Overview
Science Museum is an **interactive and educational website** designed to spark curiosity about science among children. The site provides engaging content, a fun layout, and information about exhibitions to encourage young learners.

## 🚀 Live Demo
[View Science Museum Website](https://olekb2001.github.io/Semester-Project/)

## 📂 Features
- **Kid-friendly UI** with engaging colors and visuals.
- **Information about exhibitions** to encourage museum visits.
- **Interactive elements** to make learning fun.
- **Fully responsive design** for **desktop, tablet, and mobile**.

## 🛠️ Technologies Used
- **HTML5** - Structure and content organization.
- **CSS3 (Flexbox)** - Styling and responsive layout.
- **GitHub** - Version control and project management.

##Improvements Based on Feedback:
- Enhanced color contrast and readability for accessibility.

## Future Enhancements:
- Add interactive science quizzes to make learning more engaging.
- Improve SEO and performance optimization.
